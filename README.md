# XpertEO

Site privé de préparation du futur site officiel XpertEO. Interface française, design clair violet/vert citron, pages commerciales, diagnostic persistant et administration protégée.

- [Architecture et périmètre réel](docs/ARCHITECTURE.md)
- [Gestion, variables, déploiement et maintenance](docs/OPERATIONS.md)
- [Contrôles et limites de validation](docs/QA.md)

Stack effective : React/TypeScript, conventions Next.js App Router sur runtime Vinext pour Sites/Cloudflare, D1 SQLite et migrations Drizzle. Aucun faux backend, client, résultat ni témoignage. Voir les limites de la version privée avant toute ouverture au public.
