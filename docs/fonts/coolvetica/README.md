# Coolvetica

Heading font supplied by the user in `coolvetica.zip`.

- Regular: `public/fonts/coolvetica/coolvetica-regular.otf`
- Italic: `public/fonts/coolvetica/coolvetica-italic.otf`
- Global heading styles: `app/globals.css`, using `--font-heading`.

The archive's original license and information file are preserved here. The
included desktop license does not cover serving or embedding the font on a
website. Obtain the appropriate webfont license and confirm the permitted font
files before publishing the platform with Coolvetica.
